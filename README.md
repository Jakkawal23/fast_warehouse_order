# ระบบเปิดบิลด่วน (Warehouse Order System)

**Warehouse Order System** คือ Web Application สำหรับจัดการรายการสินค้าและเปิดบิลอย่างรวดเร็วในคลังสินค้า ถูกออกแบบมาให้ใช้งานง่าย รวดเร็ว และไม่ต้องพึ่งพาระบบฐานข้อมูล (Client-Side Only) เหมาะสำหรับการจดบันทึกรายการสินค้าที่รวดเร็วผ่านมือถือหรือแท็บเล็ต

## ✨ ฟีเจอร์หลัก (Key Features)

1. **ทำงานโดยไม่ต้องมี Database (Client-Side Storage)**
   - ข้อมูลทั้งหมดจะถูกบันทึกไว้ใน `localStorage` ของเบราว์เซอร์ 
   - หากรีเฟรชหน้าเว็บหรือปิดเปิดใหม่ ข้อมูลรายการสินค้าและรูปภาพจะไม่สูญหาย

2. **ระบบจัดการรูปภาพประสิทธิภาพสูง (Advanced Image Handling)**
   - **รองรับหลายรูปภาพ (Multiple Images):** สามารถแนบรูปภาพได้หลายรูปต่อ 1 รายการ
   - **ปุ่มถ่ายรูปและคลังรูปแยกกัน:** มีปุ่มกดเปิดกล้องถ่ายรูปได้ทันที (รองรับบนมือถือ) หรือเลือกรูปจากคลังภาพ
   - **บีบอัดรูปอัตโนมัติ (Auto Compression):** ก่อนจัดเก็บ รูปภาพจะถูกลดขนาดความกว้างสูงสุดเหลือ 400px และลดคุณภาพเหลือ 70% เพื่อป้องกันปัญหา `localStorage` เต็ม
   - **Real-time Preview & Viewer:** แสดงรูปภาพขนาดเล็กทันทีที่เลือก และสามารถคลิกที่รูปเพื่อดูขนาดใหญ่แบบ Full-screen ได้

3. **รองรับหลายภาษา (Multi-language Support / i18n)**
   - รองรับ 4 ภาษา: ไทย (Thai), จีน (Chinese), อังกฤษ (English), พม่า (Burmese)
   - ข้อความบนหน้าเว็บ, หัวข้อ Modal, รวมไปถึง Placeholder ในช่องกรอกข้อมูล จะเปลี่ยนภาษาทันทีเมื่อผู้ใช้เลือกจาก Dropdown โดยไม่ต้องรีเฟรชหน้า

4. **ออกรายงานเป็น PDF (PDF Export)**
   - แปลงรายการสินค้าทั้งหมดออกมาเป็นไฟล์เอกสาร PDF
   - จัดรูปแบบเป็น **ตารางที่สวยงามและเป็นทางการ**
   - ดึงรูปภาพสินค้ามาแสดงในตารางรายงานด้วย
   - **บังคับหัวข้อตารางเป็น ไทย/จีน เสมอ** เพื่อรองรับการทำงานในคลังสินค้าระหว่างประเทศ

5. **UI/UX ที่ตอบสนองทุกอุปกรณ์ (Responsive & Clean UI)**
   - ออกแบบด้วย **Tailwind CSS** แสดงผลแบบ Card UI ที่สวยงามและอ่านง่าย
   - หน้าจอปรับขนาดอัตโนมัติ ไม่ว่าจะเปิดบน PC, Tablet หรือ Smartphone

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **HTML5:** โครงสร้างหน้าเว็บพื้นฐาน
- **Tailwind CSS (CDN):** เฟรมเวิร์กสำหรับจัดการดีไซน์ (Utility-first CSS)
- **Vanilla JavaScript:** จัดการลอจิกทั้งหมดแบบไม่พึ่งพา Framework (State Management, DOM Manipulation, i18n, Image Base64 Encoding)
- **FontAwesome:** ไอคอนตกแต่งเพื่อความสวยงามและเข้าใจง่าย
- **html2pdf.js:** ไลบรารีสำหรับสร้างและดาวน์โหลดไฟล์ PDF จาก HTML

## 📁 โครงสร้างไฟล์ (File Structure)

- `index.html` : ไฟล์หลักที่รวมโครงสร้าง UI, หน้าต่าง Modal, ปุ่มกด และเรียกใช้ไลบรารีต่างๆ
- `style.css` : สไตล์เพิ่มเติมที่ Tailwind ไม่ครอบคลุม เช่น การทำ CSS Grid สำหรับรูปภาพเล็กๆ และรูปแบบตารางเฉพาะตอนพิมพ์ PDF
- `script.js` : ไฟล์ลอจิกการทำงานหลัก (เก็บข้อมูล, แปลภาษา, แปลงรูปภาพ, สร้าง PDF)

## 🚀 วิธีการติดตั้งและใช้งาน (How to run)

เนื่องจากระบบเป็น **Client-Side Only** จึงไม่ต้องติดตั้ง Server หรือ Database ใดๆ ทั้งสิ้น
1. Clone หรือดาวน์โหลดโปรเจกต์นี้ลงเครื่อง
2. ดับเบิ้ลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ใดก็ได้ (เช่น Chrome, Safari, Edge)
3. เริ่มต้นใช้งาน เพิ่มรายการ ถ่ายรูป และ Export PDF ได้ทันที!

> **ข้อควรระวัง:** ข้อมูลทั้งหมดถูกเก็บไว้ในเบราว์เซอร์ หากคุณทำการ "ล้างข้อมูลประวัติการเข้าชม (Clear Browsing Data / Clear Cache)" ข้อมูลบิลและรูปภาพที่บันทึกไว้จะหายไปทั้งหมด
